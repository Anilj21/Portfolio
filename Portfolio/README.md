# Anil Jangid Portfolio

Interactive static portfolio website for Anil Jangid.

## Open

Open `index.html` in a browser. No build step is required.

## Included Documents

- `assets/docs/Anil-Jangid-CV.pdf`
- GitHub is linked to `https://github.com/Anilj21`
- LinkedIn is linked to `https://in.linkedin.com/in/anil-jangid-a03992293`

## Customize

- Add live project URLs or repository URLs to the project cards when ready.
- Update `assets/hero-workspace.png` if you want a personal portrait or custom image.
- Edit colors, spacing, and interactions in `styles.css` and `script.js`.
